# Stackable drill-storage covers

The existing smooth PETG covers remain available. Each of the five 1×1 drill-storage sets also has a separate stackable cover, retaining the existing collar/snap interface and engraved set label.

- **SC-1 — Stacking:** The top of each stackable cover has an approximately 4.4 mm stacking lip above the 7 mm-unit body datum. Its socket receives the full 4.4 mm of the existing 1×1 foot (0.7 mm lower bevel, 1.8 mm straight band, 1.9 mm upper bevel), so a seated holder advances by whole 7 mm units. Only the stackable cover's lip widens to 42 mm (about 0.25 mm per side beyond the 41.5 mm body); the foot socket retains the PETG sliding fit. Source: user choice of the draft [Gridfinity design-reference drawing](https://gridfinity.xyz/specification/), whose 2U example totals 18.4 mm (14 + 4.4), with full foot seating.
- **SC-2 — Compatibility and exception:** Smooth covers, original 41.5 mm bodies and bases (including their snap joints and foot profile) remain unchanged. The stackable variants fit the same collars and keep their existing minimum tool-tip clearance. The 42 mm lip consumes the entire nominal 42 mm grid pitch, and its 41.72 mm sliding-fit mouth leaves only about 0.14 mm wall per side: this is an experimental, printer-dependent exception to the 0.8 mm printable-wall rule, not an assertion of strength, successful slicing or adjacent-cell clearance under tolerances. Source: user decision to prioritize the draft profile while retaining existing bases.
- **SC-3 — Print:** Stackable covers are one-piece PETG prints, top-down with the mouth up. Expose removable breakaway socket support as a Boolean parameter on all five covers, enabled by default. Disabling it removes only the sacrificial lattice and attachment nibs, leaving the cover and socket unchanged; use slicer support or verify the unsupported bridge before printing without it. Source: user request to add support directly to the model, revised by user confirmation 2026-09-28. Remove built-in support and all attachment nibs before stacking.

Physical printer-to-printer fit, the thin lip's slicing and durability, support removal, and interference between adjacent holders need printed-part acceptance before loading a stack. The original smooth covers remain the support-free alternative.
