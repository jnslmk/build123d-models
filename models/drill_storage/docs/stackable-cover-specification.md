# Stackable drill-storage covers

The existing smooth PETG covers remain available. Each of the five 1×1 drill-storage sets also has a separate stackable cover, retaining the existing collar/snap interface and engraved set label.

- **SC-1 — Stacking:** The top of each stackable cover locates the lower 2.5 mm of another holder's 1×1 Gridfinity foot (the 0.7 mm lower bevel and 1.8 mm straight section). The receiving socket is a sliding PETG fit around the shared foot profile, stays inside the 41.5 mm footprint, and leaves the upper 1.9 mm foot bevel outside the socket. Source: user request to allow Gridfinity stacking; shared foot dimensions in `box.py`.
- **SC-2 — Compatibility:** Smooth covers and bases are unchanged; stackable covers fit the same collars and keep a whole-7-mm assembled height and the existing minimum tool-tip clearance. Source: user confirmation of separate variants preserving the existing base snap fit.
- **SC-3 — Print:** Stackable covers are one-piece PETG prints, top-down with the mouth up. Include removable breakaway support in the model beneath the socket floor; do not require slicer-generated support for the broad socket ceiling. Source: user request to add the support directly to the 3D model. Remove it before stacking.

The socket and support are for printed holders on the 1×1 shared foot. Physical printer-to-printer fit and removal effort should be checked on a printed part before loading a tall stack.
