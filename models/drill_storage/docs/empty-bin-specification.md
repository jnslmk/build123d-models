# Empty Gridfinity drill-storage bin

- **EB-1 — Separate container:** Add a general-purpose bin alongside the existing tool-specific drill holders; its default cavity is empty and undivided. Do not change the holders' bases, cartridges, or covers. Source: user request and confirmation, 2026-09-28.
- **EB-2 — Footprint and height:** Expose Gridfinity base dimensions X and Y and container height in 7 mm Gridfinity units. Default body height is 5U (35 mm); footprint remains 1×2 and lid height remains 6.5 mm. The bin is comparable in purpose and proportions to the referenced ultra-light Gridfinity bins, without importing their source geometry. Source: user request and confirmation; `gridfinity-bins` reference and the existing `drill_storage.box` 42 mm pitch and foot profile; default-height user request, 2026-09-30.
- **EB-3 — Removable stackable lid:** A separately printable lid closes the bin and receives a Gridfinity foot for stacking. Expose lid height, defaulting to the smallest printable height compatible with the closure and stacking seat. Source: user request and confirmation. Its mating geometry and print support are deferred until the bin anchor is accepted; do not assume the existing drill-holder snap collar applies to an empty bin.
- **EB-4 — Generator controls:** Match the referenced generator's parameter options on this bin anchor: X/Y half-grid sizing and half-foot placement controls, adjustable wall thickness and ultra-light base, magnet pockets and dimensions, dividers and counts, optional label tabs (placement, per-section behavior, dimensions and lightened supports), and scoops with adjustable radius. Default wall is 1 mm if it preserves a printable, lid-compatible rim; otherwise use the smallest width that does. Source: user confirmation, 2026-09-28. These options modify the bin, not the deferred lid.
- **EB-5 — Print support and presentation:** Expose the lid's breakaway socket supports as a Boolean parameter, enabled by default to preserve the supported print. Disabling it produces the same lid without sacrificial geometry. Present the PETG bin body in the drill-storage black and the PETG lid in the family's translucent cover color, both as individual models and together in the closed scene. Source: user request and confirmation, 2026-09-28; colors from `drill_storage.hex.config` and `drill_storage.tools.COVER_GLASS`.
- **EB-6 — Generator-style default base:** Replace the bin's hollow-from-below, cross-braced feet and full-width raised floor with closed 1 mm print-bed plates and foot cavities open to the bin interior. Let each foot's thin plate form its own interior floor, with a raised seam between adjacent cells as in the referenced generator image. Expose bottom thickness (0 means use wall thickness); retain the stackable lid's existing mating rim and foot envelope. Match the supplied settings for the default 1×2 bin (height now 5U per EB-2): 1 mm wall, ultra-light base and label supports on, no magnets, divider switch on with zero dividers in each axis, labels and scoops off, and no mouse-ear brim. Source: user reference images and explicit purpose/design confirmation, 2026-09-28; default-height user request, 2026-09-30.

PETG is the default material. Printer-specific fits and removable-support effort require physical print calibration.
