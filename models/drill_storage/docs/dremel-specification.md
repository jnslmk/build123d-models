# Gridfinity Dremel tool holder

- **DR-1 — Independent model:** Add a dedicated drill-storage model for Dremel tools without changing the existing holders or general-purpose bin. Source: user confirmation, 2026-09-28.
- **DR-2 — Fit and footprint:** The holder occupies 1×2 Gridfinity cells and stores tools with 2.5 mm diameter shanks and lengths up to 50 mm upright. Source: user request and confirmation, 2026-09-28.
- **DR-3 — Reference boundary:** The linked Printables holder is inspiration for an upright tool rack, not evidence that its lid or hole arrangement is required. No separate cover or underside closure is accepted for this slice. Source: clarification and confirmation, 2026-09-28.

Default material: PETG. The number and pitch of positions, bore depth, and body height are implementation choices; print calibration determines the final real-world bore fit.
