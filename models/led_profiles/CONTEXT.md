# LED profile model language

This glossary owns physical terminology for the `led_profiles` family. The
Stella specification and CAD contract use these terms; they do not redefine
requirements here.

## Stella profile connectors

**Vertex core**:
The central body at a Stella vertex, where three profile arms meet.
_Avoid_: Connector when it could mean an arm or an electrical connector.

**Core web**:
The continuous plate-like body joining a vertex core's branch roots.

**Core buttress**:
A localized reinforcing rib tying an arm-seat region into the core web or
central body.

**Profile arm**:
The structural connector between one lamp-profile end and a vertex core.
_Avoid_: Core when referring to the branch rather than the central body.

**Profile keeper**:
The removable retaining piece that completes the capture of a profile at its
support.

**Organic core form**:
A continuous three-branch outline with broad, smoothly blended roots; the term
describes the outline, not a uniform body thickness.
_Avoid_: Round core as a synonym; rounded transitions do not imply a circular
body.

**Primary suspension line**:
A load-carrying hanging line between an upper vertex core and the overhead
collector.
_Avoid_: Leg without a qualifier; this is not a printed profile arm.

**Collector**:
The common metal junction above Stella where the primary suspension lines meet
the main hanger.
_Avoid_: Core; the vertex cores belong to the printed frame below.

**Core attachment loop**:
The short, closed textile-cord loop linking an upper vertex core to its primary
suspension line.
_Avoid_: Core sling when it implies the superseded sewn-webbing loop; safety,
which backs up the common upper connection rather than this attachment.
