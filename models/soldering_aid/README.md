# SP16/SP17 soldering aid

One L-profile extrusion holds one SP16 and one SP17 connector while soldering.
The broad lower leg carries the connectors and prints flat; the rear leg makes
the profile self-supporting. The plate contains printed female threads, so the
connectors screw directly into the aid; the holes are deliberately not
interchangeable:

- left: SP16, **M16 × 1**
- right: SP17, **M17 × 1**

Print it flat on the broad lower leg in PETG. Thread clearance is 0.30 mm on
the female major diameter; print one test before committing a connector pair,
since inexpensive third-party SP connectors vary.
